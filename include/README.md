## 📂 Структура проекта

Репозиторий разбит на логические модули, каждый из которых отвечает за свой уровень абстракции:

*   **`pdp_11/`** — Ядро эмулятора. Логика процессора (CPU), конвейер команд и регистры.
*   **`types/`** — Строгая типизация. Эмуляция 8-битных (Byte) и 16-битных (Word) данных.
*   **`utils/`** — Вспомогательный инструментарий. Логирование, дебаг и парсинг бинарных файлов.
*   **`tests/`** — Модульное тестирование. Гарантия стабильности работы каждой инструкции.

---

## 🛠️ Подробное описание модулей и функций

### 🧠 Модуль `pdp_11` (Ядро процессора)
Этот модуль содержит основной цикл процессора (Fetch-Decode-Execute) и эмулирует регистры общего назначения (R0-R7, включая SP и PC).

### 📊 Модуль `types` (Типы данных и Память)
PDP-11 работает с байтами и словами. Модуль предотвращает переполнение и эмулирует адресное пространство (включая Memory Mapping для портов ввода-вывода IO).

### 🔧 Модуль `utils` (Утилиты и Отладка)
Инструменты для загрузки ассемблерного кода и красивого вывода состояния машины (Trace log).

### 🧪 Модуль `tests` (Тестирование)
Набор тестов для валидации процессора. Использование тестов исключает регрессию при добавлении новых фич.
