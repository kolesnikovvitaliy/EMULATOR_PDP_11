# 📑 Модуль управления командами архитектуры PDP-11

Компонент ядра эмулятора процессора PDP-11. Отвечает за жизненный цикл команд, декодирование операндов, парсинг режимов адресации и трассировку инструкций.

---

## 🧱 Архитектура модуля

Модуль состоит из четырех заголовочных файлов, разделяющих публичный интерфейс, внутренние структуры и конфигурацию системы команд.

*   `include/pdp_11/command/command.h` — Публичный интерфейс управления контекстом команды.
*   `include/pdp_11/command/command_p.h` — Приватные структуры данных, маски и парсеры операндов.
*   `include/pdp_11/command/commands.h` — Декларация обработчиков конкретных инструкций.
*   `include/pdp_11/command/commands_list.h` — Таблица сопоставления кодов операций и масок.

## 🛠 Публичный интерфейс (`command.h`)

Реализует паттерн **Opaque Structure** (непрозрачная структура). Внешние модули оперируют указателями, не имея прямого доступа к внутренним полям `command_t`. Это гарантирует инкапсуляцию.

### 📋 Функции жизненного цикла

#### `command_new`
```c
struct command_t *command_new();
```
*   **Описание**: Выделяет динамическую память под структуру команды и инициализирует её поля нулями.
*   **Результат**: Указатель на структуру `command_t` или `NULL` при нехватке памяти.
*   **Безопасность**: Требует обязательного вызова `command_destroy` для предотвращения утечек памяти.

*Пример использования:*
```c
#include "pdp_11/command/command.h"

void process_instruction() {
    struct command_t *cmd = command_new();
    if (cmd == NULL) {
        // Ошибка: не удалось выделить память
        return;
    }
    // Логика обработки...
    command_destroy(&cmd);
}
```

#### `command_create`
```c
void command_create(struct command_t **command);
```
*   **Описание**: Безопасный оберточный метод инициализации. Принимает адрес указателя и записывает туда адрес выделенной памяти.
*   **Предусловие**: Аргумент `command` не должен быть равен `NULL`.
*   **Постусловие**: `*command` содержит валидный адрес в куче.

*Пример использования:*
```c
#include "pdp_11/command/command.h"

struct command_t *cmd = NULL;
command_create(&cmd);

if (cmd != NULL) {
    // Память успешно выделена, объект готов к работе
}
```

#### `command_destroy`
```c
void command_destroy(struct command_t **command);
```
*   **Описание**: Освобождает выделенные ресурсы и зануляет исходный указатель.
*   **Безопасность**: Защищает от уязвимости **Use-After-Free**. Если `command` или `*command` равны `NULL`, операция завершается без ошибок.

*Пример использования:*
```c
#include "pdp_11/command/command.h"

struct command_t *cmd = command_new();
// Использование объекта...

command_destroy(&cmd);
// Теперь cmd == NULL. Повторный вызов безопасен:
command_destroy(&cmd);
```

## 🔒 Приватный интерфейс (`command_p.h`)

Раскрывает внутреннее представление команд, битовые флаги структуры аргументов инструкции и функции низкоуровневого парсинга.

### 🎛 Битовые маски параметров
Флаги определяют структуру и количество аргументов в слове команды:
*   `NO_PARAMS` (`0`) — Инструкция без операндов (например, `RESET`, `WAIT`, `HALT`).
*   `HAS_DD`    (`1`) — Инструкция содержит только операнд назначения (Destination).
*   `HAS_SS`    (`2`) — Инструкция содержит только операнд источника (Source).

### 🗂 Структуры данных

#### `command_t`
Главный описатель инструкции для внутренней таблицы декодирования.
```c
typedef struct {
    word_t  mask;                 // Битовая маска для выделения кода операции
    word_t  opcode;               // Базовый код операции (Opcode)
    byte_t *name;                 // Строковая мнемоника команды (например, "MOV")
    void (*do_commands_command)(  // Указатель на функцию-исполнитель команды
        struct pdp_11_t *,
        address_word_t,
        word_t,
        byte_t
    );
    byte_t params;                // Конфигурация параметров (NO_PARAMS, HAS_DD и др.)
} command_t;
```

#### `arg_t`
Контейнер для хранения вычисленного адреса операнда и значения по этому адресу.
```c
typedef struct {
    word_t value;  // Значение, извлеченное из памяти или регистра
    word_t addr;   // Итоговый исполнительный адрес операнда
} arg_t;
```

#### `op_code_t`
Пара распакованных аргументов для двухоперандных инструкций.
```c
typedef struct {
    arg_t ss;      // Данные операнда Source (источник)
    arg_t dd;      // Данные операнда Destination (назначение)
} op_code_t;
```

### ⚙️ Внутренние функции парсинга и трассировки

#### `__get_mr`
```c
op_code_t __get_mr(struct pdp_11_t *pdp, word_t word_command);
```
*   **Назначение**: Декодирует режимы адресации (Mode/Register) для обоих операндов (Source и Destination) на основе текущего состояния процессора.

#### `__get_args`
```c
arg_t __get_args(struct pdp_11_t *pdp, word_t word_command);
```
*   **Назначение**: Извлекает и вычисляет адресную информацию для одного операнда. Используется в однооперандных командах.

#### `__print_command`
```c
void __print_command(address_word_t addr, word_t word_command, byte_t *name_command);
```
*   **Назначение**: Форматированный вывод текущей выполняемой команды в консоль эмулятора (дизассемблирование на лету).
*   **Формат вывода**: `[Адрес]: [Машинный код] [Мнемоника]`

## 🚀 Сквозной пример работы модуля

Пример интеграции публичных и приватных функций внутри главного цикла выполнения инструкций эмулятора CPU:

```c
#include "pdp_11/command/command.h"
#include "pdp_11/command/command_p.h"

void execute_next_instruction(struct pdp_11_t *pdp) {
    address_word_t pc = 001000;       // Текущий адрес счетчика команд PC
    word_t fetched_word = 0010102;     // Считанный машинный код команды MOV R1, R2

    // 1. Логируем чтение команды в консоль отладки
    __print_command(pc, fetched_word, (byte_t *)"MOV");

    // 2. Инициализируем контекст команды через публичный интерфейс
    struct command_t *current_cmd = NULL;
    command_create(&current_cmd);

    // 3. Выполняем разбор аргументов с помощью приватной функции
    op_code_t operands = __get_mr(pdp, fetched_word);

    // [Внутренняя логика процессора: выполнение операции над operands.ss и operands.dd]

    // 4. Уничтожаем контекст и освобождаем ресурсы кучи
    command_destroy(&current_cmd);
}
```
