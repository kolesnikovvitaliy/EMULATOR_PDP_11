# 📑 Справочник команд процессора PDP-11

> **PDP-11** — легендарная 16-разрядная вычислительная система. Данный репозиторий содержит систематизированный перечень процессорных инструкций, структуру их опкодов, влияние на флаги состояния и правила адресации.

⚠️ **Важно:** Все числовые значения в таблицах приведены в **восьмеричной (octal)** системе счисления.

## 🔍 Сокращения и условные обозначения

### 1. Структура поля Opcode

| Символ | Описание значения | Размер |
| :---: | :--- | :---: |
| **B** | Признак разрядности: `0` — слово (word), `1` — байт (byte) | 1 бит |
| **SS** | Поле источника (Source field) | 6 бит |
| **DD** | Поле приемника (Destination field) | 6 бит |
| **R** | Индекс регистра (R0-R5, SP, PC) | 3 бита |
| **N** | Числовое значение | 3 бита |
| **NN** | Числовое значение | 6 бит |
| **TT** | Числовое значение | 8 бит |
| **XX** | Смещение (Адрес относительного перехода от -128 до +127) | 8 бит |

### 2. Регистры и системные элементы
* **`Rn`** — Регистр общего назначения (16 бит, `n` от 0 до 5)
* **`SP`** — Указатель стека / Stack Pointer (16 бит, аналог `R6`)
* **`PC`** — Счётчик команд / Program Counter (16 бит, аналог `R7`)
* **`PS`** — Слово состояния процессора / Processor Status (16 бит)

### 3. Операнды и параметры
* **`a`** — Относительный адрес (Relative address)
* **`b`** — Пусто для операций со словом, либо символ `B` для байтовых операций
* **`s`** / **`d`** — Источник (source) / Приемник (destination)
* **`n`** — Номер регистра (от 0 до 5)
* **`nn`** — 16-битное выражение (число от 0 до 65535)
* **`r`** — Регистр общего назначения, SP или PC
* **`t`** — Номер прерывания/ловушки (от 0 до 255)

### 4. Математические и логические операции
* **`+`**, **`-`**, **`*`**, **`/`**, **`^`** — Сложение, вычитание, умножение, деление, возведение в степень
* **`&`** — Логическое **И** (AND)
* **`~`** — Логическое отрицание **НЕ** (NOT)
* **`v`** — Логическое включающее **ИЛИ** (OR)
* **`x`** — Логическое исключающее **ИЛИ** (XOR)
* **`<-`**, **`->`** — Циклический сдвиг влево / вправо
* **`{ }`**, **`< : >`** — Комбинация операндов / диапазон бит
* **`#`** — Данная инструкция поддерживается не всеми моделями PDP-11

# Моды адресации PDP-11 / БК-0010

Документация по режимам (модам) адресации для аргументов источника (`SS`) и приемника (`DD`).

## Общие моды адресации (Регистры R0–R7)

| Мода | Обозначение | Пример | Описание |
| :---: | :--- | :--- | :--- |
| **0** | `Rn` | `inc R3` | **Регистровая:** Операнд находится в регистре R3. |
| **1** | `(Rn)` | `inc (R3)` | **Косвенно-регистровая:** В R3 лежит адрес операнда. |
| **2** | `(Rn)+` | `inc (R3)+` | **Автоинкрементная:** В R3 лежит адрес операнда. После обращения `R3` увеличивается на 2. |
| **3** | `@(Rn)+` | `inc @(R3)+` | **Косвенная автоинкрементная:** В R3 лежит адрес ячейки, в которой находится адрес операнда. После обращения `R3` увеличивается на 2. |
| **4** | `-(Rn)` | `inc -(R3)` | **Автодекрементная:** `R3` уменьшается на 2, затем новое значение используется как адрес операнда. |
| **5** | `@-(Rn)` | `inc @-(R3)` | **Косвенная автодекрементная:** `R3` уменьшается на 2, затем новое значение используется как адрес ячейки с адресом операнда. |
| **6** | `X(Rn)` | `inc 2(R3)` | **Индексная:** Адрес операнда вычисляется как сумма константы `X` (в примере: 2) и содержимого `R3`. |
| **7** | `@X(Rn)` | `inc @2(R3)` | **Косвенная индексная:** Сумма константы `X` и `R3` дает адрес ячейки, в которой лежит адрес операнда. |

## Особенности работы по 7 регистру (Счетчик команд — PC)

При использовании 7-го регистра (`PC`) в коде ассемблера применяются специальные синтаксические обозначения:

| Мода | Обозначение | Пример | Описание |
| :---: | :--- | :--- | :--- |
| **2** | `#константа` | `mov #3, R0` | **Непосредственная (Immediate):** Константа (в примере: 3) находится прямо в коде программы. |
| **3** | `@#адрес` | `mov @#100, R0` | **Абсолютная (Absolute):** Чтение/запись значения напрямую по указанному адресу (в примере: 100). |
| **6** | `адрес` | `mov 100, R0` | **Относительная (Relative):** Адрес вычисляется относительно текущего значения `PC`. Берется значение по адресу 100. |
| **7** | `@адрес` | `mov @100, R0` | **Косвенная относительная (Relative Deferred):** По адресу 100 лежит адрес, по которому находится итоговое значение. |
